# بنك الكلمات المفتاحية والوسوم — V3.0.0

النسخة النهائية المستقرة من مشروع بنك الكلمات المفتاحية والوسوم، والمهيأة للعمل مباشرة على GitHub Pages.

## الوظائف الأساسية

- تطبيق ويب ثابت بالكامل باستخدام HTML وCSS وJavaScript وJSON.
- واجهة متجاوبة للجوال والكمبيوتر.
- بناء استعلامات للكلمات المفتاحية والوسوم والمعرفات.
- دعم 8 لغات و5 منصات بحث.
- نطاقات استعلام: دقيق، موسع، شامل.
- إضافة كلمة رئيسية وكلمات مخصصة.
- حفظ سجل الاستعلامات محليًا داخل المتصفح.
- لا توجد قاعدة بيانات أو خادم خلفي أو أدوات تتبع.

## محتوى النسخة النهائية

1. الهيكل الأساسي.
2. الأمن.
3. السياسة.
4. الدين والفكر.
5. الإعلام والرأي العام.
6. الاقتصاد والمجتمع.
7. السفر والحدود.
8. النسخة النهائية المستقرة.

## النشر على GitHub Pages

1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى جذر المستودع.
3. افتح `Settings → Pages`.
4. اختر `Deploy from a branch`.
5. اختر فرع `main` والمجلد `/root` ثم احفظ الإعدادات.

> قد يمنع فتح `index.html` مباشرة عبر `file://` تحميل ملفات JSON. تعمل النسخة بصورة طبيعية على GitHub Pages أو أي خادم ملفات ثابت.
