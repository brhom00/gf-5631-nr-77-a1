# بنك الكلمات المفتاحية والوسوم — V3.0.1

تطبيق ويب ثابت مهيأ للعمل مباشرة على GitHub Pages، لبناء استعلامات رصد متعددة اللغات والمنصات.

## أبرز وظائف الإصدار

- زر «ابحث الآن» لبناء الاستعلام وفتح المنصة بخطوة واحدة.
- معاينة فورية للكلمات قبل البحث، مع استبعاد أي كلمة مؤقتًا بالنقر عليها.
- مرجع داخل الصفحة يعرض محتوى كل مجموعة باللغة المختارة.
- شرح واضح لمستويات توسعة البحث: دقيق، موسع، شامل.
- تكييف صيغة الاستعلام تلقائيًا حسب Google وX وYouTube وTikTok وFacebook.
- حقل «إضافة معرفات مخصصة» عند اختيار نوع المعرفات.
- عدم إظهار بيانات الإصدار التقنية للمستخدم داخل الواجهة.
- سجل محلي داخل المتصفح دون قاعدة بيانات أو أدوات تتبع.

## النشر على GitHub Pages

1. فك ضغط الملف.
2. ارفع **محتويات المجلد** إلى جذر المستودع، بحيث يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع.
3. افتح `Settings → Pages`.
4. اختر `Deploy from a branch`.
5. اختر فرع `main` والمجلد `/ (root)` ثم احفظ.

> لا ترفع ملف ZIP نفسه، ولا تضع ملفات المشروع داخل مجلد فرعي.
