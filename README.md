# بنك الكلمات المفتاحية والوسوم — V4.1

نسخة ثابتة تعمل على GitHub Pages دون خادم خلفي.

## تحديث V4.1
- إعادة ترتيب الواجهة إلى أربع خطوات متتابعة.
- إخفاء الخيارات المتقدمة ومرجع المجموعات والسجل داخل أقسام قابلة للفتح.
- تحسين تجربة الجوال وتقليل التشتت البصري.
- إصلاح مسار ترجمة الكلمات والوسوم المخصصة.
- البحث أولًا في الترجمات الداخلية للبنك.
- استخدام Google Translate API غير الرسمي، ثم MyMemory كخدمة احتياطية.
- عرض تقدم الترجمة وحالات النجاح والفشل بوضوح.
- منع تنفيذ البحث عند الحاجة إلى ترجمة ولم تُجهز بعد.
- دعم «وسوم مخصصة» إلى جانب «كلمات مخصصة».

## التحديث على GitHub
فك الضغط، ثم ارفع جميع الملفات فوق الملفات الموجودة عبر:
`Add file → Upload files → Commit changes`

جميع أسماء الملفات والمسارات محفوظة، لذلك ستُستبدل الملفات المتطابقة تلقائيًا. لا يوجد ملف قديم مطلوب حذفه في هذا الإصدار.
