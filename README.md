# منصة الرصد الرقمي — V5.0

إعادة تصميم كاملة للواجهة بأسلوب Mobile First مع الحفاظ على محرك البحث والبيانات.

## أبرز التغييرات
- واجهة مختصرة للاستخدام السريع من الجوال.
- هوية أخضر غامق وعودي وخلفية رقمية خافتة.
- نقل اللغة إلى قسم محتوى البحث بجوار التصنيف.
- محرر موحد للكلمات: حذف، إعادة، تعديل بالضغط على الكلمة، وإضافة مباشرة.
- زر بحث ثابت أسفل الشاشة.
- إخفاء الخيارات الثانوية داخل أقسام مطوية.
- بقاء الزمن الهجري والميلادي والسجل والمرجع.

## التحديث على GitHub Pages
ارفع جميع الملفات فوق النسخة الحالية ثم نفّذ Commit. لا يلزم حذف الملفات القديمة.
